# Predicting-Diabetes-with-KNN-Pima-Indians-Dataset
This project uses the K-Nearest Neighbors (KNN) algorithm to predict diabetes outcomes using the Pima Indians dataset. It includes data cleaning, model training, and performance evaluation, highlighting the role of distance-based classification in healthcare data.

# Overview
- This project applies the K-Nearest Neighbors (KNN) classification algorithm to predict the likelihood of diabetes in patients using the Pima Indians Diabetes dataset. The dataset includes medical attributes such as glucose level, blood pressure, BMI, and more. The goal is to classify whether or not a patient is likely to have diabetes based on these features.

# Goals
- Load and explore the Pima Indians Diabetes dataset
- Clean and preprocess the data
- Apply the KNN algorithm for classification
- Evaluate model performance using accuracy and confusion matrix
- Understand the impact of choosing different values for k

# Tools Used
- Python
- Jupyter Notebook
- Pandas, Numpy
- Matplotlib, sSeaborn
- Scikit-learn (KNeighborsClassifier)

# Key Findings
- KNN achieved solid performance in predicting diabetes risk based on medical data
- Model performance varied depending on the number of neighbors (k) used
- Data visualization helped identify patterns and class imbalances
- Simpler models like KNN can still be effective in medical prediction tasks
